autocomplete

The classic typeahead: normalize each keystroke, wait for a pause, skip a repeated term, then search and cancel the search still in flight.

Sample: the drawn spec as code, one frame per millisecond

// at(ms, v): v at ms; end(ms): complete at ms; 1 frame = 1 ms
const at = (ms, v) => timer(ms).pipe(map(() => v));
const end = (ms) => timer(ms).pipe(ignoreElements());
const search = (term) => timer(6).pipe(map(() => [term]));
merge(
  at(1, 'R'), at(3, 'Rx'), at(5, 'RxJ'), at(7, 'RxJS'),
  at(11, 'RXJS'), at(17, 'Rx'), at(22, 'RxJ'), end(27),
).pipe(
  map(s => s.toLowerCase()),
  debounceTime(3),
  distinctUntilChanged(),
  switchMap(search),
)

5 essential criteria

the input
the field value after each keystroke: R, Rx, RxJ, RxJS, then RXJS, Rx, RxJ
map
lowercases, so RxJS and RXJS become the same term
debounceTime(3)
lets a term through only after 3 quiet frames; typing again cancels the wait
distinctUntilChanged
drops a term equal to the one before it: no second search for rxjs
switchMap(search)
starts a 6-frame search per term and unsubscribes the one still running when a new term arrives

Resulting sink

[rxjs] at 16, [rxj] at 31, complete at 31

Workflow

  1. R, Rx, RxJ, RxJS arrive at 1, 3, 5, 7; each cancels the previous wait, and rxjs comes through at 10. Its search starts and answers [rxjs] at 16.
  2. RXJS at 11 becomes rxjs again at 14; distinctUntilChanged drops it, so the running search is left alone.
  3. Rx at 17 comes through at 20 and starts a search; RxJ at 22 comes through at 25 and switchMap cancels that search one frame before its answer.
  4. The rxj search answers [rxj] at 31; the input completed at 27, so the output completes with that last search.

In the spec

Twelve lanes: the input, then the map, debounceTime, distinctUntilChanged and switchMap stages, each with its output lane. The debounce row shows three cancelled windows before the first that emits; the distinct lane has a gap at 14; inner 2 is the search cut at 25, a bar with no marble; every inner row hangs from the distinct lane.

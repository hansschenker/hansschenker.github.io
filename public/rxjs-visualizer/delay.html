delay

Shifts every value by the same amount of time; order and spacing are kept.

Sample: the drawn spec as code, one frame per millisecond

// at(ms, v): v at ms; end(ms): complete at ms; 1 frame = 1 ms
const at = (ms, v) => timer(ms).pipe(map(() => v));
const end = (ms) => timer(ms).pipe(ignoreElements());
merge(at(3, 'a'), at(6, 'b'), end(9))
  .pipe(delay(2))

3 essential criteria

delay
2 frames for every value
order and spacing
unchanged; a and b stay 3 frames apart
completion
passes once nothing is pending; here at 9, after the delayed b at 8

Resulting sink

a at 5, b at 8, complete at 9

Workflow

  1. a at 3 is emitted at 5.
  2. b at 6 is emitted at 8.
  3. the source completes at 9; b is already out, so the output completes at 9 too.

In the spec

Each value drops onto the operator row and a 2-frame window runs before the arrow drops it onto the output lane; the completion has no window.

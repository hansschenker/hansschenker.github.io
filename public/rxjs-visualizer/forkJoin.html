forkJoin

Waits for every input to complete, then emits an array of their last values.

Sample: the drawn spec as code, one frame per millisecond

// at(ms, v): v at ms; end(ms): complete at ms; 1 frame = 1 ms
const at = (ms, v) => timer(ms).pipe(map(() => v));
const end = (ms) => timer(ms).pipe(ignoreElements());
forkJoin([
  merge(at(1, 'a'), at(4, 'b'), at(10, 'c'), at(12, 'd'), at(14, 'e'), end(16)),
  merge(at(8, 'f'), at(11, 'g'), at(13, 'h'), at(15, 'i'), at(18, 'j'), end(20)),
  merge(at(2, 1), at(5, 2), at(7, 3), at(9, 4), end(13)),
])

3 essential criteria

one emission
when the last input completes: s2 at 20
its value
the last value of each input, in input order: e, j, 4
an input completing empty
makes the output complete without a value

Resulting sink

[e, j, 4] at 20, complete at 20

Workflow

  1. s3 completes first, at 13, with 4 as its last value; s1 at 16 with e.
  2. nothing is emitted meanwhile; every earlier value is forgotten as a later one arrives.
  3. s2 completes at 20 with j: [e, j, 4] is emitted and the output completes on that frame.

In the spec

Nothing on the output lane until 20; the pill appears together with the completion, (x|), on the frame the last lane completes.

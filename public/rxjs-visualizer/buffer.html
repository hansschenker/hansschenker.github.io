buffer

Collects values into an array and emits it every time a notifier emits.

Sample: the drawn spec as code, one frame per millisecond

// at(ms, v): v at ms; end(ms): complete at ms; 1 frame = 1 ms
const at = (ms, v) => timer(ms).pipe(map(() => v));
const end = (ms) => timer(ms).pipe(ignoreElements());
const closing = merge(at(5, 'B'), at(11, 'B'), at(17, 'B'), end(19));
merge(
  at(1, 'a'), at(3, 'b'), at(5, 'c'), at(7, 'd'), at(9, 'e'),
  at(11, 'f'), at(13, 'g'), at(15, 'h'), at(17, 'i'), end(19),
).pipe(buffer(closing))

3 essential criteria

notifier
b, emitting B at 5, 11 and 17
on each B
the buffer so far is emitted and a new one starts
on completion
the open buffer is emitted, even empty, then the output completes

Resulting sink

[a, b, c] at 5, [d, e, f] at 11, [g, h, i] at 17, [] at 19, complete at 19

Workflow

  1. a, b, c arrive at 1, 3, 5; the B at 5 comes after c on that frame and emits [a, b, c].
  2. d, e, f fill the next buffer and B at 11 emits it; g, h, i and B at 17 the same.
  3. the source completes at 19 with an empty buffer open: [] is emitted, then the completion.

In the spec

Every B on the b lane drops onto the operator row where a pill leaves for the output lane. c and the first B share frame 5, c first, so it is counted. The completion at 19 emits the empty F.

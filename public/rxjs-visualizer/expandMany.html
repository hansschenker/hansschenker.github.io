expand

expand with a project function that returns two values per input: every value is emitted and expanded again, so the recursion is a tree.

Sample: a project function emitting more than one value

of(1).pipe(
  expand((value) => (value < 4 ? of(value * 2, value * 2 + 1) : EMPTY))
)

3 essential criteria

initial value
1
project
value * 2, value * 2 + 1
recursion limit
value < 4; from 4 on, project returns EMPTY

Resulting sink

1, 2, 4, 5, 3, 6, 7

Workflow

  1. 1 is emitted first, then project(1) returns of(2, 3).
  2. when 2 is emitted, expand immediately treats it as a new value and calls project(2): of(4, 5) is subscribed and emitted before of(2, 3) gets to 3; 4 and 5 expand to EMPTY.
  3. then 3 is emitted and project(3) gives 6 and 7; every inner has completed, so the output completes. A synchronous inner makes this depth-first.

In the spec

The inner is a cold of two values, a = 0 at 2 frames and b = 1 at 6, mapped to 2x + k. 1 at 2 spawns inner 1, which emits 2 at 4 and 3 at 8; each of those is expanded in turn: inner 2, from inner 1, emits 4 at 6 and 5 at 10, inner 3 emits 6 at 10 and 7 at 14. 4, 5, 6 and 7 return EMPTY, noted on the operator row. The inners take time, so the tree unfolds in time order, 1, 2, 4, 3, 5, 6, 7, with 5 and 6 sharing frame 10; the synchronous sample above is depth-first instead.

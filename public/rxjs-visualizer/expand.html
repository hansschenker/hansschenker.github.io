expand

Emits every value and feeds it back into the project function; the values of the resulting inner are emitted and expanded too, until an inner is EMPTY.

Sample: doubling until 8

of(1).pipe(expand((value) => (value < 8 ? of(value * 2) : EMPTY)))

3 essential criteria

initial value
1
project
value * 2, one value per input
recursion limit
value < 8; from 8 on, project returns EMPTY

Resulting sink

1, 2, 4, 8

Workflow

  1. 1 is emitted first, then project(1) returns of(2).
  2. 2 is emitted and expanded at once: project(2) gives 4, and project(4) gives 8.
  3. 8 is emitted; project(8) is EMPTY, every inner has completed, so the output completes.

In the spec

The single outer value 1 spawns an inner that emits 2; that 2 is an outer value again, so the next row hangs from it (from inner 1) and emits 4, then 8; project(8) returns EMPTY, noted on the operator row, and the output completes when the last inner does. One value per input makes the recursion a chain; expandMany, next in the picker, makes it a tree.

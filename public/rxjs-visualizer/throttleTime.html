throttleTime

Emits a value at once, then drops everything for the given time.

Sample: the drawn spec as code, one frame per millisecond

// at(ms, v): v at ms; end(ms): complete at ms; 1 frame = 1 ms
const at = (ms, v) => timer(ms).pipe(map(() => v));
const end = (ms) => timer(ms).pipe(ignoreElements());
merge(
  at(1, 'a'), at(3, 'x'), at(5, 'y'), at(10, 'b'),
  at(14, 'x'), at(16, 'c'), at(17, 'x'), end(21),
).pipe(throttleTime(5))

3 essential criteria

silence
5 frames after an emitted value
values inside it
dropped, not delayed (leading: true, trailing: false)
the first value after it
is emitted on the frame it arrives, unlike debounceTime and auditTime

Resulting sink

a at 1, b at 10, c at 16, complete at 21

Workflow

  1. a at 1 is emitted at once and opens 5 frames of silence, to 6: x at 3 and y at 5 are dropped.
  2. b at 10 is emitted and opens silence to 15; x at 14 is dropped.
  3. c at 16 is emitted and opens silence to 21; x at 17 is dropped. The source completes at 21 and the output with it.

In the spec

Watch the operator row: each emitted value opens a window with the arrow at its start, and the values that drop onto a running window get no arrow: those are the dropped ones.

defaultIfEmpty

Emits a default value if the source completes without having emitted anything.

Sample: the drawn spec as code, one frame per millisecond

// at(ms, v): v at ms; end(ms): complete at ms; 1 frame = 1 ms
const at = (ms, v) => timer(ms).pipe(map(() => v));
const end = (ms) => timer(ms).pipe(ignoreElements());
end(8).pipe(defaultIfEmpty(42))

3 essential criteria

default
42
an empty source
emits the default on the frame it completes, then the completion
a source with values
passes unchanged; the default is never used

Resulting sink

42 at 8, complete at 8

Workflow

  1. the source runs to 8 without a value.
  2. it completes at 8.
  3. defaultIfEmpty emits 42 on that frame, then the completion.

In the spec

The source completes at 8 without a value; x = 42 appears on that frame together with the completion, (x|).
